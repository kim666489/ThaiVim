                         คู่มือการใช้งาน NCURSES C++ (THAI)

1. ภาพรวมและการติดตั้ง (OVERVIEW & SETUP)
--------------------------------------------------------------------------------
ติดตั้งไลบรารี NCurses บน Debian/Ubuntu:
   $ sudo apt install libncurses5-dev libncursesw5-dev

คอมไพล์โปรแกรม C++ ร่วมกับ NCurses:
   $ g++ -O2 main.cpp -o my_tui -lncurses

* ข้อควรจำ: NCurses ใช้ระบบพิกัดแบบ (Y, X) เสมอ!
  โดย Y คือ แถว (แนวตั้ง/Row) และ X คือ คอลัมน์ (แนวนอน/Column)
  มุมบนซ้ายสุดของหน้าจอคือพิกัด (0, 0)


2. การตั้งค่าและควบคุมเทอร์มินัล (TERMINAL CONFIGURATION & CONTROL)
--------------------------------------------------------------------------------
initscr()
   - เริ่มต้นโหมด NCurses (ต้องเรียกใช้เป็นคำสั่งแรกสุดของโปรแกรม)

endwin()
   - คืนค่าคอนฟิกของเทอร์มินัลกลับสู่ปกติ (ต้องเรียกใช้ก่อนจบโปรแกรมเสมอ)

raw()
   - ปิดระบบ Line Buffering (เมื่อกดปุ่มปุ๊บ getch() จะรับค่าทันทีโดยไม่ต้องรอ Enter)
   - ปิดสัญญาณควบคุมปกติ เช่น Ctrl+C หรือ Ctrl+Z (จะถูกมองเป็นปุ่มกดธรรมดา)

cbreak()
   - ปิดระบบ Line Buffering เหมือน raw() แต่ยังคงปล่อยให้สัญญาณควบคุม (Ctrl+C) ทำงานได้

noecho()
   - ซ่อนตัวอักษรที่ผู้ใช้พิมพ์ ไม่ให้แสดงขึ้นประจานบนหน้าจอโดยอัตโนมัติ

echo()
   - เปิดให้ตัวอักษรที่พิมพ์แสดงบนหน้าจอตามปกติ

keypad(stdscr, TRUE)
   -เปิดใช้งานการรับปุ่มพิเศษ (เช่น ปุ่มลูกศร, F1-F12, Home, End)

curs_set(0)
   - ตั้งค่าการแสดงผลของเคอร์เซอร์กะพริบ:
     0 = ซ่อนเคอร์เซอร์ (มองไม่เห็นเลย)
     1 = แสดงผลปกติ (ขีดเส้นใต้หรือกล่องกะพริบปกติ)
     2 = แสดงผลแบบเด่นชัดพิเศษ (กล่องทึบหนา)

nodelay(stdscr, TRUE)
   - ตั้งค่าโหมด Input แบบไม่บล็อกแถว (Non-blocking) ถ้าไม่มีการกดปุ่ม getch() จะคืนค่า ERR ทันที

timeout(ms)
   - ตั้งเวลาหน่วงในการรอปุ่มกดของ getch() หากไม่มีการกดปุ่มภายในเวลา 'ms' (มิลลิวินาที) 
     getch() จะคืนค่า ERR (ถ้าใส่ค่าลบจะรอไปเรื่อยๆ จนกว่าจะมีคนกด)


3. การแสดงผลและการวาดหน้าจอ (SCREEN OUTPUT & DRAWING)
--------------------------------------------------------------------------------
printw("format", ...)
   - พิมพ์ข้อความตามรูปแบบ ณ ตำแหน่งเคอร์เซอร์ปัจจุบัน (ใช้งานเหมือน printf)

mvprintw(y, x, "format", ...)
   - ย้ายเคอร์เซอร์ไปที่พิกัด (Y, X) แล้วพิมพ์ข้อความทันที

wprintw(win, "format", ...)
   - พิมพ์ข้อความลงในหน้าต่างย่อย (Window) เฉพาะที่กำหนด

mvwprintw(win, y, x, "format", ...)
   - ย้ายเคอร์เซอร์ไปที่พิกัด (Y, X) ภายในหน้าต่างย่อยที่กำหนด แล้วค่อยพิมพ์ข้อความ

refresh()
   - สั่งอัปเดตข้อมูลในบัฟเฟอร์ขึ้นสู่หน้าจอเทอร์มินัลจริง (NCurses จะไม่วาดอะไรเลยจนกว่าจะเรียกใช้คำสั่งนี้)

wrefresh(win)
   - สั่งอัปเดตการแสดงผลเฉพาะหน้าต่างย่อย (Window) ที่กำหนด

clear()
   - ล้างหน้าจอทั้งหมด (stdscr) ให้ว่างเปล่า (จะมีผลหลังสั่ง refresh)

wclear(win)
   - ล้างหน้าต่างย่อยที่กำหนดให้ว่างเปล่า

move(y, x)
   - ย้ายเคอร์เซอร์ไปที่พิกัด (Y, X) โดยไม่ได้พิมพ์ข้อความใดๆ

getmaxyx(stdscr, max_y, max_x)
   - มาโครสำหรับดึงขนาดหน้าจอ/หน้าต่างปัจจุบัน โดยจะเก็บความสูงไว้ใน 'max_y' และความกว้างใน 'max_x'
   - หมายเหตุ: ห้ามใส่เครื่องหมาย & หน้าตัวแปร (เช่น &max_y) เพราะฟังก์ชันนี้เป็น macro!

box(stdscr, 0, 0)
   - วาดกรอบสี่เหลี่ยมรอบขอบของหน้าต่าง/หน้าจอที่ระบุ (เลข 0 สองตัวหลังหมายถึงใช้เส้นขอบมาตรฐาน)

clrtoeol()
   - ล้างตัวอักษรทั้งหมดนับตั้งตำแหน่งเคอร์เซอร์ปัจจุบันไปจนสุดบรรทัดนั้นๆ


4. การรับปุ่มกดจากผู้ใช้ (USER INPUT PROCESSING)
--------------------------------------------------------------------------------
getch()
   - รอรับปุ่มกดจากคีย์บอร์ด 1 ตัวอักษร แล้วส่งค่ากลับมาเป็นรหัสปุ่ม (Integer)

mvgetch(y, x)
   - ย้ายเคอร์เซอร์ไปที่พิกัด (Y, X) ก่อน จากนั้นจึงรอรับปุ่มกด

wgetch(win)
   - รอรับปุ่มกดภายในบริบทของหน้าต่างย่อยที่กำหนด

* รหัสปุ่มลูกศรมาตรฐาน (ต้องเปิด keypad(stdscr, TRUE) ก่อนใช้งาน):
  - KEY_UP        : ปุ่มลูกศรขึ้น
  - KEY_DOWN      : ปุ่มลูกศรลง
  - KEY_LEFT      : ปุ่มลูกศรซ้าย
  - KEY_RIGHT     : ปุ่มลูกศรขวา
  - KEY_ENTER     : ปุ่ม Enter (บางระบบใน raw โหมดอาจส่งค่ากลับมาเป็น 10 หรือ '\n')
  - KEY_BACKSPACE : ปุ่มลบถอยหลัง


5. ระบบสีและสไตล์ตัวอักษร (COLORS & TEXT ATTRIBUTES)
--------------------------------------------------------------------------------
start_color()
   - เปิดใช้งานระบบสีในเทอร์มินัล (ต้องเรียกใช้ทันทีหลัง initscr())

has_colors()
   - ตรวจสอบว่าเทอร์มินัลที่ใช้งานรองรับการแสดงผลแบบสีหรือไม่ (คืนค่า TRUE/FALSE)

init_pair(pair_id, foreground_color, background_color)
   - สร้างคู่สีผสมของตัวเอง โดยระบุรหัสสีตัวอักษร และสีพื้นหลัง
   - ตัวอย่าง: init_pair(1, COLOR_GREEN, COLOR_BLACK); (ตัวหนังสือเขียว พื้นหลังดำ)

attron(COLOR_PAIR(pair_id))
   - เปิดใช้งานสไตล์ตัวอักษรหรือคู่สีตามรหัสที่กำหนดไว้

attroff(COLOR_PAIR(pair_id))
   - ปิดใช้งานสไตล์ตัวอักษรหรือคู่สีนั้นๆ

* สไตล์อักษรที่ใช้บ่อย (Style Constants):
  - A_NORMAL     : ตัวหนังสือปกติ
  - A_BOLD       : ตัวหนังสือหนา/เด่นชัด
  - A_UNDERLINE  : ตัวหนังสือขีดเส้นใต้
  - A_REVERSE    : สลับสีตัวหนังสือกับสีพื้นหลัง (Invert)
  - A_BLINK      : ตัวหนังสือแบบกะพริบ (บางเทอร์มินัลอาจไม่รองรับ)
  - A_DIM        : ตัวหนังสือสีหม่น/ความสว่างครึ่งเดียว

* รหัสสีมาตรฐาน (Default Colors):
  - COLOR_BLACK (ดำ)   - COLOR_RED (แดง)      - COLOR_GREEN (เขียว)    - COLOR_YELLOW (เหลือง)
  - COLOR_BLUE (น้ำเงิน)  - COLOR_MAGENTA (ชมพู)  - COLOR_CYAN (ฟ้า)       - COLOR_WHITE (ขาว)


6. การจัดการหน้าต่างย่อย (CUSTOM WINDOW MANAGEMENT)
--------------------------------------------------------------------------------
WINDOW* win = newwin(height, width, start_y, start_x)
   - จองหน่วยความจำและสร้างหน้าต่างลอยบานใหม่ซ้อนบนหน้าจอหลัก

delwin(win)
   - ลบหน้าต่างย่อยที่สร้างขึ้น และคืนหน่วยความจำให้ระบบ

derwin(parent_win, height, width, local_y, local_x)
   - สร้างหน้าต่างย่อยซ้อนอยู่ข้างในหน้าต่างหลักอีกทีหนึ่ง โดยอ้างอิงพิกัดภายในหน้าต่างหลัก


7. โค้ดโครงสร้างโปรแกรมตัวอย่าง (C++)
--------------------------------------------------------------------------------
#include <ncurses.h>

int main() {
    // 1. ตั้งค่าระบบเริ่มต้น
    initscr();
    raw();
    keypad(stdscr, TRUE);
    noecho();
    curs_set(0);

    if (has_colors()) {
        start_color();
        init_pair(1, COLOR_CYAN, COLOR_BLACK);    // คู่สีที่ 1: ฟ้า-ดำ
        init_pair(2, COLOR_YELLOW, COLOR_BLACK);  // คู่สีที่ 2: เหลือง-ดำ
    }

    // 2. วาดหน้าจอ UI เริ่มต้น
    attron(COLOR_PAIR(1) | A_BOLD);
    mvprintw(2, 5, "=================================");
    mvprintw(3, 5, "    NCURSES INITIALIZED READY    ");
    mvprintw(4, 5, "=================================");
    attroff(COLOR_PAIR(1) | A_BOLD);

    attron(COLOR_PAIR(2));
    mvprintw(6, 5, "กดปุ่ม [ขึ้น] / [ลง] เพื่อทดสอบระบบ");
    mvprintw(7, 5, "กดปุ่ม [Q] เพื่อออกจากโปรแกรม");
    attroff(COLOR_PAIR(2));
    
    box(stdscr, 0, 0); // วาดกรอบรอบหน้าจอ
    refresh();

    // 3. ลูปดักจับปุ่มกด (Event Loop)
    int ch;
    while ((ch = getch()) != 'q' && ch != 'Q') {
        move(9, 5);
        clrtoeol(); // ล้างตัวหนังสือเก่าบนบรรทัดที่ 9 ตั้งแต่คอลัมน์ที่ 5 เป็นต้นไป
        box(stdscr, 0, 0); // วาดกล่องทับเพื่อไม่ให้กรอบแหว่งตอนเคลียร์บรรท
        
        switch(ch) {
            case KEY_UP:
                mvprintw(9, 5, "สถานะ: กดปุ่ม เลื่อนขึ้น [UP]");
                break;
            case KEY_DOWN:
                mvprintw(9, 5, "สถานะ: กดปุ่ม เลื่อนลง [DOWN]");
                break;
            default:
                mvprintw(9, 5, "ปุ่มที่กดคือ: %c (รหัสปุ่ม: %d)", ch, ch);
                break;
        }
        refresh();
    }

    // 4. คืนค่าระบบก่อนปิดโปรแกรม
    endwin();
    return 0;
}
